# Odak Lojistik UI V6

Bu sürüm V5 üzerine hazırlanmıştır.

## Yeni
- Ctrl/Cmd + K global komut paleti
- Masaüstünde sol üst menü butonundan komut paletine erişim
- Gerçek global light/dark theme yüzeyleri
- Sayfa geçiş animasyonu
- Premium sticky table header / hover / input focus sistemi
- Buton press ve hover micro-interaction standardı
- Upload/drop zone iyileştirmeleri
- Yönetici, sipariş, parsiyel, yeni sipariş ve MUI ekranları için ortak premium UI katmanı
- Sidebar görsel yoğunluk, aktif item glow ve logo alanı iyileştirmeleri
- Ana sayfa kart/panel/dark mode polish

## Çalıştırma
Kendi .env dosyanızı ekleyin, ardından:

npm install
npm start

Not: node_modules, build, .git, .vs ve .env pakete dahil değildir.
