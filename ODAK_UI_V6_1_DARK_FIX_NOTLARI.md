# ODAK UI V6.1 — Dark Mode Compatibility Fix

Bu sürüm V6 üzerindeki dark-mode uyumsuzluklarını giderir.

- MUI theme light/dark arasında dinamik değişir.
- Sipariş Oluştur dark tokenları ve tüm modal/table/dropzone yüzeyleri eşitlendi.
- Yeni Sipariş, Parsiyel Sipariş, Fasdat, Arkas ve Teslim Noktaları dark yüzeyleri eşitlendi.
- Gelir/Gider inline-style ekranlarına dark-mode uyum sınıfları eklendi.
- Sefer Fiyatlandırma, Proje Tanımları ve Yönetici ekranları için dark yüzey/input/table uyumu eklendi.
- Özet Analiz ekranındaki Tailwind light utility sınıfları dark modda uyumlu hale getirildi.
- MUI Dialog/Menu/Popover/Table/Input bileşenleri global dark palette ile senkronize edildi.
- Dark scrollbar görünümü eklendi.
